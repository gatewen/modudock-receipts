# modudock-receipts

modudock 自我進化的**外部時間戳回執**。這裡只放**序號和加鹽雜湊**，沒有任何程式內容、對照表或答案。

- 用途：事前登記雜湊，讓 GitHub 伺服器記下時間（Molt 進化設定 0.8.0 的 N3/N4「何時外部落地」）
- 保護：所有分支和標籤都**禁止強制覆寫、禁止刪除**（ruleset，沒有例外名單）
- 寫入：agent 用只有 Contents 寫入權限的細粒度權杖，不能改 repo 設定
- 限制：repo 擁有者的管理權限仍在同一台電腦上，擋不住同一個帳號的蓄意冒充（0.8.0 已明寫）；任何強制覆寫都會在 GitHub 留下事件紀錄
